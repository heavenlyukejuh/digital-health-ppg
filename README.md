# End-to-End PPG Device & Digital Health System

This project simulates how a medical device (pulse oximeter) and a digital health wearable 
process PPG signals to extract metrics such as heart rate, SpO₂, and signal quality.

The goal:
- Integrate R&D device engineering
- Apply systems engineering thinking
- Perform signal simulation & filtering
- Analyze clinical artifacts (motion, poor contact, interference)
- Build ML models for signal quality or HR prediction
- Produce digital-health-level metrics and dashboards

This project represents a hybrid role across:
- Clinical engineering
- R&D engineering
- Systems engineering
- Digital health
- ML in healthcare
- Clinical data science
